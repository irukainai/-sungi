# 共テ政経

共通テスト「公共、政治・経済」の対策クイズ。1ファイル（`index.html`）で動く、ビルド不要の静的ページ。

## 機能
- 22単元・全206問（自作）。政治分野と経済分野に分類
- 自信（勘／たぶん／これ間違えてたら切腹）に応じた忘却曲線。10分ごとに更新
- 解いた問題は10分ロック
- 問題図鑑、共テ形式の問題（12問）、金黒モード

## 公開の手順（GitHub Pages）
1. GitHubで新しいリポジトリを作る（Public）
2. `index.html`、`README.md`、`.nojekyll` をアップロードする（「Add file」→「Upload files」）
3. 「Settings」→「Pages」→ Branch を `main`、フォルダを `/ (root)` にして保存
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開ける。このURLを友達に送る

## データについて
- 学習記録は、各自のブラウザ（localStorage）に保存される。友達同士で記録が混ざることはない
- 端末やブラウザを変えると、記録は引き継がれない。ブラウザのデータを消すと記録も消える

## 注意
- 問題・解説は自作で、実際の共通テストと同じ形式・難度とは限らない。難易度の★や単元の分類は作者の目安
- 事実関係は作者の知識による。過去問や教科書、資料集で必ず確認すること
- 外部通信は、Google Fonts（フォント読み込み）のみ
